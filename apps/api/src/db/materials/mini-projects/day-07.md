# Day 7: Testing TypeScript APIs & OpenAPI Docs

## Mini-Project: Integration Test Suite & OpenAPI Spec

Write a focused integration test suite and generate interactive API documentation.

### Core (Required)
* Write at least 6 integration tests covering happy paths (`201`/`200`), validation errors (`400`), unauthorized requests (`401`), and missing resources (`404`).
* Generate an interactive API documentation endpoint (`/docs`) from your request/response schemas.

### Stretch
* Enable coverage reporting and reach at least `80%` coverage on your service layer.

### Challenge
* Build a reusable `createAuthenticatedAgent(role)` test helper to remove auth boilerplate across protected endpoint tests.
